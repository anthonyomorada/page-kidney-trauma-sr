# Traumatic Page Kidney Systematic Review

[![DOI](https://img.shields.io/badge/DOI-10.1136%2Ftsaco--2025--002041-blue)](https://doi.org/10.1136/tsaco-2025-002041)
[![Journal](https://img.shields.io/badge/Journal-TSACO-blue)](https://tsaco.bmj.com/)
[![PRISMA](https://img.shields.io/badge/PRISMA-2020-blue)](https://www.prisma-statement.org/)

This repository contains the data, analysis code, and review materials supporting:

> Morada AO, Kropp Lopez A, Droney A, Lopez R. Traumatic Page kidney: a systematic review and patient report of bilateral Gerota's fascia release. *Trauma Surgery & Acute Care Open*. 2026;11:e002041. doi:10.1136/tsaco-2025-002041

The purpose of this repository is auditability. Readers should be able to inspect the extracted dataset, review the screening/data-extraction materials, and rerun the R analysis used for the systematic review.

## Start With The Analysis

For audit/reproducibility review, start here:

1. `data/trauma-page-kidney-table.csv` - source extraction dataset.
2. `protocols/data-analysis.Rmd` - analysis code that reads the dataset and generates outputs.
3. `protocols/data-analysis.html` - rendered analysis report for quick review.
4. `data/README.md` and `protocols/README.md` - short folder-level guides.

## Reproducing The Analysis

From the repository root, render the analysis with R:

```r
rmarkdown::render("protocols/data-analysis.Rmd")
```

The analysis expects `data/trauma-page-kidney-table.csv` to be present at the repository root path. It writes the cleaned tables back to `data/tpk-table.csv` and `data/table1.csv`.

Main R package dependencies:

```r
install.packages(c(
  "dplyr",
  "flextable",
  "ggplot2",
  "glue",
  "kableExtra",
  "knitr",
  "officer",
  "rmarkdown",
  "stringr",
  "tidyr"
))
```
