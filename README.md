## 📚 About This Repository

This repository contains all data, analysis, and documentation from our systematic review and case report on traumatic Page kidney. The work presents the first published case of bilateral traumatic Page kidney managed with bilateral Gerota's fascia release.

The systematic review follows PRISMA 2020 guidelines and includes a comprehensive analysis of trauma-related Page kidney cases from the literature.

## 🔬 Methodology

- **Search Strategy**: PubMed, Embase, Web of Science databases
- **Time Period**: Literature from 1969-2024
- **Guidelines**: PRISMA 2020 compliant systematic review
- **Analysis**: R-based statistical analysis with full reproducible code
