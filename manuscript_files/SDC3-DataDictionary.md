# Data Extraction Instructions for Manuscript Reviewers

## Overview

This document provides detailed instructions for extracting data from trauma-related Page kidney case reports and studies. Please follow the data dictionary specifications exactly to ensure consistency across all reviewers and facilitate accurate analysis.

## Data Dictionary

| **Column Name** | **Description**                                       | **Format/Example**                               |
| --------------- | ----------------------------------------------------- | ------------------------------------------------ |
| reference       | Full citation of the case report or study source.     | *Aragona et al., 1991*                           |
| pdf             | Availability of the full-text PDF.                    | y = Yes, n = No                                  |
| include         | Inclusion status in the systematic review.            | y = Included, n = Excluded, reason               |
| year            | Year of publication.                                  | *1991, 2010*                                     |
| age             | Patient age at presentation.                          | Numeric value (*e.g., 25, 89*)                   |
| gender          | Patient gender.                                       | m = Male, f = Female                             |
| pmh             | Relevant past medical history.                        | Free text (*e.g., “HTN; DM; CKD”*)               |
| onset-y         | Time from trauma to Page Kidney diagnosis (in years). | Numeric (*e.g., 0.25 = 3 months*)                |
| mechanism       | Mechanism of traumatic injury.                        | *mvc*, *fall*, *assault*, etc.                   |
| ss              | Symptoms and signs at presentation.                   | Free text (*e.g., “flank pain, hypertension”*)   |
| hypertension    | Presence of hypertension as part of presentation.     | y = Yes, n = No                                  |
| ua              | Presence of abnormal urinalysis findings.             | Free text or y/n                                 |
| grade           | Grade of renal injury (if reported).                  | Numeric (*e.g., 3, 4*) or empty                  |
| size-cm         | Size of the perirenal hematoma or collection (cm).    | Numeric (*e.g., 6.6*)                            |
| page-type       | Type of compressive lesion causing Page Kidney.       | *hematoma*, *urinoma*, *lymphocele*              |
| laterality      | Laterality of kidney involvement.                     | left, right, bilateral, allograft                |
| treatment       | Management approach used.                             | Free text (*e.g., “decortication, IR drainage”*) |
| fu-status       | Renal function outcome at follow-up.                  | s = Survived, d = Died                           |
| fu-y            | Length of follow-up (in years).                       | Numeric (*e.g., 0.75 = 9 months*)                |
| reviewer-1      | Reviewer #1                                           | Reviewer Initials                                |
| reviewer-2      | Reviewer #2                                           | Reviewer Initials                                |
| review-notes    | general comments                                      | Free text                                        |
